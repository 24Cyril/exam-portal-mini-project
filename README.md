# Exam Portal Mini Project

## Overview

Exam Portal Mini Project is a full-stack web application designed to streamline online examinations and course management. It provides separate dashboards for students, teachers, and administrators, enabling efficient management of courses, exams, enrollments, and student performance.

## Features

* Secure user authentication
* Role-based access (Admin, Teacher, Student)
* Course management
* Online examinations
* Student enrollment
* Performance tracking
* Dashboard analytics
* Profile management
* Firebase integration

## Tech Stack

### Frontend

* React
* TypeScript
* Vite

### Backend

* Node.js
* Express.js

### Database & Services

* Firebase Authentication
* Firebase Firestore
